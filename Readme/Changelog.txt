v1.0.10 (10.10.2026)
New
- Toolbar shows the generate buttons of the current tab (e.g. Generate - new seed / same seed on the Random tab) and an Export button.
- Tab / Shift+Tab switch between tabs (outside text fields); Ctrl+Tab always works.
- Presets: Save writes the current settings into the selected own preset; own presets can be renamed.
- Export can write straight into a mod folder (map\random\tiles and its data folder), without an extra tile folder.
Changed
- The export folder and export target are remembered between sessions.
- Remove all straits/regions/modifiers can now be undone.

v1.0.8 (26.09.2026)
New

Changed

- Restart without saving reopens the project in its last saved state.

v1.0.6 (26.09.2026)
New
- Initial Public release
- Automatic updates via GitHub: Help > Check for updates, a daily check at startup (can be switched off) and an update bar with "Update now". The new version is downloaded, its signature is checked, and the program restarts with your project reopened.
- Help menu with Changelog and About.
- Help > Report a bug: post a prefilled GitHub issue (needs a GitHub account) or send the report by email; the crash window has a Report bug button. Crash log entries are included without your personal folder names.
- Rivers tab: the river selected in the list is highlighted red on the map.
- Random Generation tab: "Generate - new seed" and "Generate - same seed" to quickly try variants.
- Rivers tab: "Regenerate - new seed" and "Regenerate - same seed".
